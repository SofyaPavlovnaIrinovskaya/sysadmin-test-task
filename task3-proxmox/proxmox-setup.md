# Отчет по установке и настройке виртуализации на базе Proxmox VE

В данном документе описан процесс развертывания гипервизора Proxmox VE и создания тестовой виртуальной машины.

---

## 1. Параметры гипервизора Proxmox VE
* **Версия Proxmox VE:** 8.x
* **Сетевой интерфейс управления:** `https://192.168.1.150:8006/`
* **Сетевой мост (Bridge):** `vmbr0` (привязан к физическому адаптеру)

---

## 2. Пошаговый процесс развертывания ВМ

### Шаг 1. Загрузка ISO-образа
1. В веб-интерфейсе Proxmox VE перешли в раздел **`local (pve)` -> `ISO Images`**.
2. Загрузили ISO-образ ОС **Ubuntu Server 22.04 LTS** (`ubuntu-22.04.3-live-server-amd64.iso`).

### Шаг 2. Создание виртуальной машины (Create VM)
Через мастер создания ВМ (**Create VM**) были заданы следующие параметры:

* **General:**
  * `Node`: pve
  * `VM ID`: 100
  * `Name`: `ubuntu-test-vm`
* **OS:**
  * `Storage`: local
  * `ISO image`: `ubuntu-22.04.3-live-server-amd64.iso`
* **System:**
  * Значения по умолчанию (QEMU Agent включен)
* **Disks:**
  * `Storage`: local-lvm
  * `Disk size`: 20 GiB
  * `Format`: raw / qcow2
* **CPU:**
  * `Cores`: 2
* **Memory:**
  * `Memory`: 2048 MiB (2 GB)
* **Network:**
  * `Bridge`: `vmbr0`
  * `Model`: VirtIO (paravirtualized)

---

## 3. Запуск и проверка работы
1. В виртуальную машину установлена операционная система Ubuntu Server.
2. Сетевой адаптер получил IP-адрес из локальной сети через bridge `vmbr0`.
3. Проверена связь с гипервизором и внешней сетью (ping).
