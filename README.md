# sysadmin-test-task
Решение практического тестового задания на позицию системного администратора (Linux, VLAN, SSH, VPN, Proxmox).
## 🛠 Выполненные задачи

### 1. Базовая настройка сети
* Настроен статический IP-адрес на сервере.
* Настроены 2 VLAN-интерфейса (`VLAN 10` и `VLAN 20`) на одном сетевом адаптере.
* **Файлы в репозитории:**
  * `task1-network/netplan.yaml` — конфигурация сети;
  * `task1-network/vlan-explanation.md` — практическое обоснование использования VLAN.

### 2. Настройка удалённого доступа
* Настроен SSH-доступ по ключам (аутентификация по паролю отключена).
* Развернут VPN-сервер и выполнено успешное подключение со второго хоста/ВМ.
* **Файлы в репозитории:**
  * `task2-remote-access/sshd_config` — конфигурационный файл SSH;
  * `task2-remote-access/vpn/` — конфигурации VPN-сервера и клиента.

### 3. Виртуализация (Proxmox VE)
* Установлен Proxmox VE и развернута тестовая виртуальная машина (либо предоставлено пошаговое описание параметров и скриншоты).
* **Файлы в репозитории:**
  * `task3-proxmox/proxmox-setup.md` — пошаговый отчет по созданию ВМ.

### 4. Документирование и Git
* Все конфигурации, текстовые описания и скриншоты структурированы по каталогам.
